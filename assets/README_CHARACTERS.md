# 角色配置說明 / Character Configuration Guide

## 📁 檔案結構

### `characters_config.csv` - 角色完整配置（主要檔案）
- **id**: 角色唯一識別碼
- **code**: 角色代號（程式碼使用，如 w=戰士, m=法師）
- **display_name**: 角色顯示名稱（中文）
- **style**: 角色風格分類
- **description**: 角色描述
- **atk**: 攻擊力 (1-100)
- **def**: 防禦力 (1-100)
- **hp**: 生命值 (50-200)
- **icon_path**: 選單小圖示路徑
- **sprite_path**: 遊戲角色精靈圖路徑

### `character_skills.csv` - 角色技能（獨立檔案）
- **character_id**: 對應 characters_config.csv 的 id
- **skill_id**: 技能唯一識別碼
- **skill_name**: 技能名稱
- **skill_type**: 技能類型 (attack/defense/special)
- **damage**: 傷害值 (0 表示無傷害)
- **cooldown**: 冷卻時間（回合數）
- **description**: 技能描述

## 🔧 如何修改

### 添加新角色
1. 在 `characters_config.csv` 添加新行（包含所有基本資訊）
2. 在 `character_skills.csv` 添加對應技能

### 調整角色屬性
- 直接修改 `characters_config.csv` 中的數值
- 建議保持總屬性點數平衡

### 修改技能
- 在 `character_skills.csv` 中調整技能參數
- 可以添加新技能或移除舊技能

## 📊 屬性平衡建議

### 總屬性點數
- 建議每個角色的 atk+def 總和在 150-170 之間
- 避免單一屬性過高（>95）或過低（<30）

### 角色類型平衡
- **平衡型**: 攻擊和防禦相近
- **攻擊型**: ATK 高，DEF 低
- **防禦型**: DEF 高，ATK 低

### HP 平衡
- **輕型角色**: HP 75-90（高攻擊，低防禦）
- **中型角色**: HP 90-110（平衡型）
- **重型角色**: HP 110-130（高防禦，低攻擊）

## ⚠️ 注意事項

1. **ID 一致性**: 確保兩個 CSV 檔案中的 character_id 一致
2. **路徑正確性**: 圖片路徑要指向實際存在的檔案
3. **數值範圍**: 
   - 攻擊力/防禦力: 1-100
   - 生命值: 50-200
4. **備份**: 修改前建議備份原始檔案

## 💡 為什麼分離技能表？

技能表保持獨立的原因：
- **一對多關係**: 每個角色可以有多個技能
- **技能複雜性**: 技能有額外的屬性（傷害、冷卻等）
- **維護便利**: 可以單獨調整技能而不影響角色基本資訊

## 🎯 簡化設計理念

### 核心屬性
- **攻擊力 (ATK)**: 影響傷害輸出
- **防禦力 (DEF)**: 影響傷害減免
- **生命值 (HP)**: 影響生存能力

### 視覺資源
- **小圖示**: 選單中的角色選擇
- **精靈圖**: 遊戲中的角色顯示（可放大使用）

### 移除的複雜元素
- 速度、技術等複雜屬性
- 耐力、特殊能力等額外系統
- 大頭像等不必要的資源
